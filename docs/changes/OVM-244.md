# OVM-244 — приватные stdin-наборы

ExecutionSpec принимает ровно один источник: inputs либо suite
(suite_id/version/checksum_sha256). Resolver загружает
`<key_prefix>/<suite_id>/<version>/suite.json` из private object storage.
Формат `sandbox.inputs.v1`: schema_version, suite_id, version, inputs.
Другие поля, несовпадение версии/checksum, превышение размера/числа кейсов
отклоняются до исполнения. Эталоны и checker остаются в tasks.
После загрузки результат связывается с хешем фактически исполненных входов.

Reader использует существующие `tests.object_storage`/`SANDBOX_TESTS_*` настройки
и `SANDBOX_FEATURE_OBJECT_STORAGE_TESTS`; bucket и prefix совпадают с tasks writer,
credentials reader должны иметь только GetObject. `tests.object_storage.enabled`
также должен быть включён. Рекомендуемый MaxBytes — 8 MiB для JSON encoding
набора с суммарным decoded stdin до 1 MiB. S3 Get ограничивает чтение до MaxBytes.
Старый формат pytest/go-test и его object keys не меняются.

Выкладывать sandbox до включения graded producer tasks. Сохранять runtime версии
в registry для старых immutable suites. Workspace hard max — 10 MiB.

Проверены race unit, vet/build, shared contracts (7 fixtures), проверки manifest
на checksum/version/unknown fields/size и контекст результата. Реальный gojudge
и S3 в этой проверке не запускались.
